IR 대시보드를 다른 PC에서 여는 방법

1. PostgreSQL 16을 보통처럼 설치하고, 서비스가 실행 중인지 확인합니다.
2. Node.js를 설치합니다.
3. 이 폴더에서 PowerShell을 열고 아래를 실행합니다.

   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\restore-db.ps1

   postgres 슈퍼유저 비밀번호를 한 번 입력합니다.
   스크립트가 앱 계정과 데이터베이스를 만든 뒤, db\ir_dashboard.sql 을 그 계정으로 넣습니다.
   덤프에는 테이블 소유자와 GRANT가 없습니다. 복원하는 앱 계정이 테이블 주인이 되므로, 받는 PC의 역할 이름을 덤프와 맞출 필요는 없습니다.

4. 의존성을 설치하고 실행합니다.

   npm run install:all
   npm run dev

브라우저 주소는 http://localhost:3000 입니다.
데이터베이스 파일은 db\ir_dashboard.sql 입니다.
.env 와 backend\.env 가 앱 설정입니다. backend\.env 가 루트 .env 보다 우선합니다.
